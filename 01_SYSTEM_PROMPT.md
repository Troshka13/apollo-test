## Блок T123 (закон 13 и CODE_RULES)
- Полностью автономен: свои шрифты `<link>`, токены реальными значениями, сброс, стили, JS. Работает на пустой странице Tilda.
- Корень `div.ag-scope.ag-<page>-<role>#ag-<page>-<nn>`, CSS только от корня; один H1 на страницу; < 100 000 байт.
- Движение — только `data-ag-anim` + движок `tools/engine_template.html` **символ в символ** (копируешь, не переписываешь). Не больше двух типов появления на блок; без своих @keyframes появления и `opacity:0` на контенте; без JS, при reduce и без CDN весь текст виден.
- Свой JS не вставляет узлы (движок следит за `childList`) — только атрибуты и классы; `draw`, `stroke-dash*`, `opacity`/`transform` узлов с `data-ag-anim` не трогать; метка `data-ag-ui-mounted`.
- Каждая версия — полный файл с новым номером и шапкой «что изменилось, дата, запись Tilda».
- Мобильная версия обязательна: 320–1440 (границы 599/600, 1023/1024), без прокрутки вбок, телефон не длиннее прошлой версии или рост объяснён.
