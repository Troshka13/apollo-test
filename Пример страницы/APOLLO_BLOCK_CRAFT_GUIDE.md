Здесь — как я думаю, проектирую, пишу и проверяю блоки: дизайн-система, анатомия блока, движение, свой JS, все фишки страниц, метод придумывания фишки, самопроверка и выдача. Версия 2 · 02.10.2026 (после приёмки: независимая модель собрала по набору новый блок — поправки внесены).

**Старшинство.** Гайд подчинён `01_SYSTEM_PROMPT.md` → `03_RULES_FACTS.md` → коду последних выданных блоков (`blocks/`). Если гайд расходится с ними — прав они. Состояние проекта (что стоит на тесте, какая страница следующая, срочное) здесь не хранится — оно в `02_PROJECT_STATE.md`.

**Набор не заменяет пак передачи.** Правила, факты и инструменты — в паке: вместе с набором обязательно приложи `HANDOFF_ALL_IN_ONE.md` (01–08 одним файлом: законы, факты-ловушки, разрешённые имена, отклонённые идеи), `knowledge/FACTS_v10.md`, `knowledge/FALLBACKS.md`, `knowledge/COPY_STANDARD.md`; для проверок — папку `tools/`. **Без имён.** В гайде и приложениях нет имён людей; в выдержках кода имя заменено на «[имя]». Имена тренеров пишешь только из списка разрешённых в `03_RULES_FACTS.md` (раздел 4) или из сообщения пользователя.

## 1. Как думать (порядок решения)
Короткая версия этого раздела лежит в `PROMPTS.md` — её можно вставить первым сообщением.

1. **Сначала факты, потом красота.** Что стоит на тесте (версии, записи `rec…`, HEAD), какой текст, какие числа подтверждены, какие кадры есть и что на них на самом деле. Нет факта — формулировка из `knowledge/FALLBACKS.md`, не выдумка.
2. **Читатель и его действие.** Кто пришёл на страницу, что он хочет понять за 10 секунд, какое действие следующее (записаться, позвонить, выбрать зал). Фишка должна помогать понять или выбрать, а не украшать.
3. **Предмет зала.** Ищи фишку в предмете этой страницы: канаты ринга, мешок, рабица клетки, маховик и педаль сайкла, ручка пульта, лампа, табло, профиль схватки, знак движения. Один мотив на страницу.
4. **Где живёт смысл блока.** Текст заморожен; фишка показывает то, что уже сказано (строку таблицы, шаг занятия, разницу направлений), — движением, связью, состоянием.
5. **Минимальная техника.** CSS-переход → атрибут на корне + CSS → WAAPI по точкам → canvas (крайний случай). Свой JS не вставляет узлы, не трогает узлы движка.
6. **Все режимы сразу.** Без JS, reduce, forced-colors, печать, сенсор, клавиатура, 320–1920 — проектируются вместе с фишкой, а не после.
7. **Сначала промт, потом код.** Промт v1 → независимое ревью → v2 с ответами → сборка → проверки → поправки §9 → выдача. Не утверждай непроведённую проверку (`not_tested` + причина).
8. **Один вопрос + решение по умолчанию.** Если неясно — задай один вопрос и сразу скажи, что сделаешь, если ответа не будет. Ждать — только перед необратимым (публикация, удаление, 301).

## 2. Два сценария

### Сценарий А — проход «дизайн, движение и фишка» по готовой странице
Пользователь присылает адрес страницы и стандартное сообщение («теперь работаем с этой страницей… разработай промт… выдай блоки удобно для копирования»). Это значит: **все блоки страницы**, текст заморожен (кроме ошибок факта и подписей кадров), меняются дизайн, состояния, движение, мобильная версия, своя фишка.

**Вход:** последние версии блоков (`blocks/<страница>/` или `kits/<страница>/`), что стоит на тесте (отчёт `tools/test_audit_console.js` от пользователя или своя сверка), страница дополнения `addon/pages/<ID>.md` (ведущий приём), факты (`03_RULES_FACTS.md`, `knowledge/FACTS_v10.md`), кадры (смотреть глазами).
**Шаги:** промт v1 (`PROMPTS.md` → «Промт прохода») → независимое ревью → промт v2 (§6 «нельзя», §7 ответы на ревью, §8 план по блокам, §8.1 вопросы, §8.2 правки факта дословно) → сборка полных файлов `v1.N+1` из прошлой версии точечными заменами → проверки (§16) → §9 «поправки по итогам проверок» → выдача (§19).
**Готово, когда:** каждый блок — полный файл с новой версией и шапкой; видимый текст = прошлой версии, кроме перечисленных правок факта; ссылки +0 −0 (или изменение объяснено); телефон не длиннее (или рост объяснён); фишка проверена во всех режимах; страница копирования / сообщения с кодом; адрес, Title, Description — каждое отдельным блоком кода.

### Сценарий Б — новый блок с нуля
**Вход:** бриф или текст владельца (если нет — текст по `knowledge/COPY_STANDARD.md` с пометкой черновых фраз `span data-ag-draft="N"`), факты, кадры, место на странице (запись, соседи сверху/снизу — чтобы раскладка не повторяла соседнюю).
**Шаги:** промт нового блока (`PROMPTS.md`) → скелет из `SKELETON_BLOCK.html` (поменять id корня, префикс классов, id символов) → разметка → CSS по §4–§6 → движение (≤ 2 типа появления) → фишка (§8, §11) → режимы (§12) → самопроверка (§16) → выдача.
**Готово, когда:** блок работает один на пустой странице; один H1 на страницу (только если это первый экран); ссылки только на живые страницы (иначе — подпись без ссылки); все числа подтверждены или помечены; < 100 000 байт; движок — копия шаблона.

**Чек-лист сценария Б** (вместо пунктов «текст = прошлой версии» из §16):
- факты в тексте — дословно из FACTS / FALLBACKS (фразу факта можно делить на части, но не менять смысл и не добавлять); микротекст интерфейса (кикер, заголовок, подписи кнопок) — по COPY_STANDARD и с `span data-ag-draft="N"`, пока владелец не утвердил;
- место на странице известно (запись, соседи, их поверхности) — иначе спроси; поверхность чередуется с соседями;
- префикс классов не занят на странице (найди все `class="ag-..__` в блоках страницы); `from` аналитики — `<страница>_<роль>` (§14);
- мотив фишки — мотив этой страницы (канаты на `/boxing`, маховик на `/cycle-samara`…), не новый;
- решения страницы соблюдены (если на странице ревью отклонило автопоказы — их нет и в новом блоке; см. карточки страницы);
- промт v1 → ревью → v2 так же, как в сценарии А (шаблон — `PROMPTS.md` §5).

## 3. Принципы фишки
- **Из предмета, не из каталога эффектов.** Канаты есть только в зале с рингом — значит «канаты ринга» на `/boxing`. Педаль и маховик — только на сайкле. Знак движения растяжки — только на растяжке. Если фишку можно перенести на любой сайт — это декор.
- **Польза формулируется одной фразой.** «Строка „Как работают“ становится видна без чтения: держат / повторяют / медленно». Нет такой фразы — нет фишки.
- **По действию читателя** (наведение, касание, выбор, прокрутка как отступление) **или один показ.** Ничего не крутится бесконечно, фон не движется сам. Один автопоказ допустим, если он объясняет, как пользоваться (подсказка шкалы, показ темпа), и только когда элемент виден.
- **Один мотив на страницу, 1–2 лёгкие интеракции на экран.** Новый блок на странице подхватывает её мотив, а не вводит свой. Главная фишка + серийные лёгкие: F10 плашка вкладок, F22 плавный FAQ, F23 нажатие кнопки, F29 зерно бумаги.
- **Не обещает движением.** Луч растяжки не уходит «глубже нарисованного» (обещание результата), цифры не крутятся счётчиком у цен, нет «бесплатно» в анимации.
- **Без JS и при reduce — статично и полно.** Весь текст виден, всё раскрыто, состояние по умолчанию осмысленное.
- **Раскладка владельца сохраняется** (решение Р2): фишка встраивается в существующую композицию, высота телефона не растёт.
- **Без видимой нумерации** (решение Р1): никаких «01–04», «Шаг 1», `counter()` — порядок показывают раскладкой, линией, стрелкой.
- **Декор вне движка — только по действию читателя** (П12): свет за курсором остаётся единственным в HOME-01, заливка контурного слова — в HOME-11; в остальных блоках — не добавлять «живой» фон, вздрагивающие значки, бегущие деления.
- **GSAP и шрифты — в каждом блоке** (К3/П11): сайтового общего слоя нет, блок автономен.
- **Отличие от соседей.** Блок не повторяет раскладку аналогичного блока на другой странице (в шапке — строка «Отличие: …»).

## 4. Дизайн-система кратко
Полные значения и дословный CSS — `APOLLO_DESIGN_REFERENCE.md`. Токены объявляются **на корне блока** реальными значениями (не `:root`, не `var(--ag-…)` снаружи).

## 5. Анатомия блока и именование

### Порядок частей (как в `SKELETON_BLOCK.html`)
1. Комментарий-шапка (паспорт) + комментарий версии.
2. `<div class="ag-scope ag-<страница>-<роль>" id="ag-<страница>-<nn>" data-ag-surface="dark|deep|paper|accent">`.
3. Шрифты (2 × preconnect + stylesheet).
4. Спрайт иконок (если нужны).
5. `<section class="ag-xx" aria-labelledby="<id>-title">` → `<div class="ag-xx__wrap">` → содержимое.
6. `<style>`: (а) корень с токенами и базовой типографикой → (б) сброс типовыми селекторами → (в) ссылки и фокус с `.ag-scope` → (г) секция, обёртка → (д) кикер, заголовок, лид → (е) компоненты → (ж) `@media (hover:hover)` → (з) ширины по убыванию (1023 → 767 → 599 → 359) → (и) `prefers-reduced-motion`, `forced-colors`, `print` → (к) хвост версии `/* ===== v1.N.0 · … ===== */` с новыми приёмами и их режимами.
7. `<script>`: свои модули (каждый — IIFE с комментарием, `"use strict"`, метка повторного запуска) → «Страховка скана» последней.
8. `<!-- Движок движения … -->` + `<script>` движка — **последним** перед `</div>` корня (только если в блоке есть `data-ag-anim` или `data-ag-magnetic`).

### Шапка-комментарий
```html
<!-- ============================================================
     APOLLO GYM · <ID> · «<заголовок дословно>» или роль · v<X.Y.Z> · <ДД.ММ.ГГГГ>
     Tilda: страница «/<адрес>», <N>-й блок, один T123, отступы 0 / 0.
     Ставится в запись rec<…> вместо «…» (что стояло в записи).
```

## 6. Мобильная версия и ширины
- **Обязательные границы:** 599/600 и 1023/1024. Проверять высоту ещё на 320, 360, 390, 767/768, 1440, 1920. Местные границы (639/640 для зерна, 899/900, 959, 479, 359) — только когда в блоке есть то, что на них меняется. Пиши целыми (`max-width:599px`); `.98` в старых блоках — наследие.
- **Нет прокрутки вбок** на 320–1920 (`scrollWidth = clientWidth`), в том числе без веб-шрифтов (Arial шире Oswald).
- **Телефон не длиннее прошлой версии**; рост — объяснить в отчёте.
- Типовые перестройки < 1024: две колонки → одна (кадр под текстом, `max-width:760px`), декор убирается (веер, контурное слово с параллаксом), вкладки 4 в ряд → 2×2 над панелью, сравнение в колонках → переключатель строк, шапка 7fr/5fr → столбец. ≤ 767: планка фактов в столбик (число 86px слева + подпись), таблица → карточки. ≤ 599: отступы 44/40, кнопки во всю ширину, радиусы 12.
- **Сравнение по строкам (subgrid):** ПК — `grid-template-rows:subgrid` в колонках, строки выровнены; < 1024 — переключатель `button[aria-pressed]` в `role="group"`, строки в одной ячейке `grid-area:1/1` + `visibility:hidden` у невыбранных (высота по самой длинной, без скачков).
- **Подгонка подписей и H1:** самое длинное слово меряется canvas `measureText`, один кегль на группу, таймер 30 мс + `ResizeObserver` + `document.fonts` (без rAF).
- **Переносы:** неразрывный пробел — только перед тире (`секции&nbsp;— факт`) и в адресах/ценах (`<span class="ag-nw">Молодогвардейская,</span> 56`, `900&nbsp;₽`). Длинная связка с `&nbsp;` даёт +40 px на 320. Подпись вкладки: `nowrap` от 375, на 320–374 перенос с `text-wrap:balance`.
- **Арифметика 320:** ширина ячейки 2×2 = (320 − 2×16 − 8)/2 = 140 px минус паддинги 2×12 = 116 px. Самое длинное слово подписи в Oswald 14px uppercase должно влезть (≈ 7,5 px на букву → 15 букв). Без веб-шрифтов (резерв Arial/Arial Narrow) буква заметно шире — считай ≈ 9,5 px на букву 14px uppercase (≈ 12 букв). Не влезает в каком-либо из двух случаев — подгонка кегля или перенос.

## 7. Движение: движок и правила
Движок (`ENGINE_TEMPLATE.html`) — общий `window.ApolloMotion` на GSAP 3.13.0 + ScrollTrigger (cdnjs). В каждом блоке — копия **символ в символ**, последней; не переписывать, не «улучшать», не сокращать.

| `data-ag-anim` | Что делает | Атрибуты (по умолчанию) |
|---|---|---|
| `rise` | прозрачность 0→1 + сдвиг | `data-ag-from` up/down/left/right/none, `data-ag-distance` 32, `data-ag-dur` 700, `data-ag-delay` 0 |
| `fade` | прозрачность | dur 800 |
| `stagger` | дети по очереди | `data-ag-children` (селектор), `data-ag-stagger` 80, dur 650 |
| `split` | слова/буквы | `data-ag-split` words/chars; один заголовок на экран |
| `draw` | путь SVG через `stroke-dash*` | dur 1200; **`data-ag-delay` не читает**; только path/line с одним `M` |
| `scale-in` | 1.07→1 | dur 1000 |
| `parallax` | сдвиг по прокрутке | `data-ag-parallax` ≤ **0,08**; триггер — ближайший `[data-ag-parallax-scope]` |
| `count` | счёт к числу | только подтверждённые числа, **не цены** |
| `marquee` | скорость бегущей строки | `data-ag-speed` 48 |
Общее: `data-ag-start` (по умолчанию `top 86%`; первый экран — `top bottom`), один раз.

**Что движок делает с DOM** (отсюда все запреты):
- пишет **inline** `opacity`, `transform`, `stroke-dasharray/-dashoffset` у своих узлов и `opacity:1` у родителя stagger → свой CSS/JS **не трогает `opacity`, `transform`, `d`, `stroke-dash*`** у узлов с `data-ag-anim` и у детей stagger. Приглушать — `stroke-opacity`, `stroke-width`, `color`, `fill`, `background`, классом на другом узле;
- ставит `data-ag-done` и `<html data-ag-motion="on|off">`; без GSAP за 2000 мс, при ошибке CDN или `prefers-reduced-motion` — `off`, всё видно;
- `MutationObserver` на `childList` корня пересканирует блок через 220 мс → **свой JS не вставляет узлы**: всё, что нужно фишке, заранее в разметке (скрыто CSS, `hidden`, `aria-hidden`). В нескольких старых блоках узлы вставлялись (canvas сетки клетки, «вмятина» мешка, `innerHTML` результата подбора) — это наследие; в новых блоках не делать.

**Правила:**
- Не больше **двух типов появления** на блок (`draw`, `parallax`, `count`, `marquee` не в счёт). Свои `@keyframes` появления и `opacity:0` на контенте — запрещены (скрывает только движок и только когда загрузился).
- Первый экран: кадр LCP без появления (`fetchpriority="high"`, только `parallax 0.06` на слое 110 %), элементам — `data-ag-start="top bottom"`.
- «Один transform — одному поведению»: появление — на обёртке, качание/наклон — на внутреннем узле; параллакс у `img`, своё движение — у `figure`.
- Магниты (`data-ag-magnetic`) в проходе снимаются; параллакс декора — ≤ 0,08.
- Карта времени: нажатие кнопки 120–160 мс (`scale(.98)`), возврат 220–280; вкладки 320–400; смена фото 180–240 (только прозрачность); появление 500–700, сдвиг 16–24; линия 600–800; наклон ±3°, только мышь. Кривая — `cubic-bezier(.22,.61,.36,1)`; возврат кнопки — `cubic-bezier(.34,1.56,.64,1)`.
- Без постоянного `requestAnimationFrame`, без покадровой анимации `filter`/`blur`/`box-shadow`; `will-change` — только на время.
- **Печать до прокрутки.** Движок ставит ещё не показанным узлам inline `opacity:0` (появление ждёт прокрутки) — при печати до прокрутки такие блоки выходят пустыми (найдено при приёмке 02.10; в выданных до 02.10 блоках этого правила нет, в DIR08 v1.1.0 — есть). Единственное разрешённое исключение из запрета трогать узлы движка — CSS печати:
```css
  @media print{
    #ag-dir08-02 [data-ag-anim],
    #ag-dir08-02 [data-ag-anim] *{opacity:1 !important;}
    #ag-dir08-02 [data-ag-anim]{transform:none !important;}
  }
```
  Свои скрытые узлы фишки внутри таких блоков — `display:none !important` в печати.
- **«Страховка скана»** — маленький IIFE в конце своего скрипта (до движка): ждёт `ApolloMotion.ready` (100 мс × 50) и вызывает `scan(root)`, если GSAP уже грузит другой блок. Дословно — в `SKELETON_BLOCK.html`.

## 8. Свой JS: паттерны с кодом
Шаблоны ниже собраны из выданных блоков и упрощены (без лишних деталей); дословный код — в эталонах и `APOLLO_FEATURE_CARDS.md`. Пишешь в ES5-стиле (`var`, `function`), без библиотек, без `innerHTML`, без rAF.

### 8.1 Каркас модуля
```js
  (function () {
    "use strict";
    var W = window, D = document;
    var root = D.currentScript && D.currentScript.closest(".ag-scope");
    if (!root || root.hasAttribute("data-ag-ui-mounted")) return;
    var items = Array.prototype.slice.call(root.querySelectorAll(".ag-xx__item"));
    if (!items.length) return;                       /* разметки нет — тихо выходим */
    root.setAttribute("data-ag-ui-mounted", "");     /* повторная вставка блока не дублирует слушатели */
    function mq(q) { return W.matchMedia ? W.matchMedia(q) : { matches: false }; }
    var still = mq("(prefers-reduced-motion: reduce)");
    var fine = mq("(min-width: 1024px) and (hover: hover) and (pointer: fine)");
    /* … */
  })();
```
`D.currentScript` работает только во время синхронного выполнения — модуль стоит в том же `<script>`, что и «страховка скана».

### 8.2 Только мышь, и проверка в момент события
```js
    el.addEventListener("pointerenter", function (e) {
      if (e.pointerType !== "mouse" || !fine.matches) return;
      /* … */
    });
    [still, fine].forEach(function (q) {
      if (q.addEventListener) q.addEventListener("change", reset); else if (q.addListener) q.addListener(reset);
    });
```
Сенсорный экран ≥ 1024 (планшет, ноутбук с тачем) не получает наведения — фишка там либо по касанию кнопки, либо автопоказом, либо её нет (в отчёт).

### 8.3 Состояние — атрибут корня, вид — CSS
```js
root.setAttribute("data-hl", r);      /* JS: только атрибут */
```
```css
#ag-dir08-02[data-hl="2"] .ag-zc__row[data-r="2"]{background:var(--hl);}
```
Снятие подсветки — с задержкой 220 мс (`pointerleave` → таймер, `pointerenter` его отменяет): переход мыши по строке через три колонки не мигает и не перезапускает фишку.

### 8.4 Готовность прорисовки `draw` — только чтением
```js
    function ready() {
      var m = D.documentElement.getAttribute("data-ag-motion");
      if (m === "off") return true;            /* движок выключен — всё уже нарисовано */
      if (m !== "on") return false;            /* ещё грузится */
      for (var k = 0; k < draws.length; k++) {
        if (!draws[k].hasAttribute("data-ag-done")) return false;
        if (Math.abs(parseFloat(W.getComputedStyle(draws[k]).strokeDashoffset) || 0) > 0.5) return false;
      }
      return true;
    }
```

### 8.5 WAAPI по точкам (движение по кривой)
Узел-«бегунок» стоит в разметке с CSS `transform-box:view-box; transform-origin:0 0`, путь только читается.
```js
      var L = path.getTotalLength(), fr = [];
      for (var k = 0; k <= 28; k++) {
        var p = path.getPointAtLength(L * k / 28);
        fr.push({ transform: "translate(" + p.x.toFixed(2) + "px," + p.y.toFixed(2) + "px)" });
      }
      anim = dot.animate(fr, { duration: 900, easing: "linear" });   /* плавность — выборкой точек */
```
Одна анимация на узел, без очереди; перебивание — `cancel()` или продолжение с текущей точки (`anim.currentTime / dur`). Для круга — аналитически (центр, радиус, угол только растёт) — см. эталон педали. После серии быстрых действий `getAnimations({subtree:true})` должен стать 0.

### 8.6 Один показ, когда видно
```js
      var io = new IntersectionObserver(function (en) {
        /* все нужные элементы ≥ 60 % → таймер 400 мс → если всё ещё видно и готово — показ, io.disconnect() */
      }, { threshold: [0, 0.6, 1] });
```
Показ не стартует, если идёт показ другого блока (соглашение `data-cue`, §8.10), при `prefers-reduced-motion`, на скрытой вкладке (`document.hidden`). Если читатель сам запустил фишку раньше — автопоказ считается использованным.

### 8.7 Текущий шаг по прокрутке (телефон)
`IntersectionObserver` с `rootMargin: "-45% 0px -50% 0px"`, шаг становится текущим через 180 мс. Один источник: на телефоне — прокрутка, на ПК — наведение.

### 8.8 Плашка, которая едет (F10)
Плашка — `::before` у списка вкладок, позиция — custom properties из `offsetLeft/Top/Width/Height` выбранной вкладки; при первой установке, `ResizeObserver`, смене раскладки 1023/1024 — класс `is-jump` (без перехода) на 60 мс. Код — `ETALON_DIR08-04_v1.1.0_tabs.html` и `APOLLO_DESIGN_REFERENCE.md` (вкладки).

### 8.9 Слушать атрибуты, а не связывать модули
Модуль фишки не лезет в чужой модуль — он слушает атрибуты корня, которые тот ставит:
```js
    new MutationObserver(function (list) {
      list.forEach(function (m) {
        var v = root.getAttribute(m.attributeName), old = m.oldValue;
        if (m.attributeName === "data-hl" && v === "2" && old !== "2") play();
      });
    }).observe(root, { attributes: true, attributeOldValue: true, attributeFilter: ["data-hl", "data-row"] });
```
Наблюдение за **атрибутами** движок не трогает (он смотрит только `childList`). Повторная установка того же значения даёт запись — так ловится «нажали ту же кнопку ещё раз».

### 8.10 Соглашение `data-cue` между блоками
Блок, который **сам** что-то показывает (автопоказ, подсказка), ставит на свой корень `data-cue` на время показа и снимает после. Другой блок перед своим автопоказом проверяет `document.querySelector(".ag-scope[data-cue]")` (не свой корень) и ждёт (до 4 с). Блоки остаются автономными: нет соседа — нет ожидания.

### 8.11 Текст и метки
- Подпись кнопки меняется через `label.firstChild.nodeValue` (не `textContent`, не `innerHTML`).
- Связь блоков одной страницы — событием (`ag:schedule` на `/schedule`) или атрибутами в URL из белого списка (`club`, `direction`, `trainer`, `days`, `who`), выбор в URL — только по действию читателя, `history.replaceState`.
- После раскрытия FAQ и других изменений высоты — `ScrollTrigger.refresh()` таймером 60 мс (`ApolloMotion.ScrollTrigger || window.ScrollTrigger`), иначе параллакс блоков ниже сбивается.
- iOS: `:active` работает только при слушателе касания — `root.addEventListener("touchstart", function () {}, { passive: true });` (в «страховке скана»).

### 8.12 Reduce на лету
Проверяй `still.matches` в момент события, а не один раз; слушай `change` → `cancel()` всех своих анимаций и возврат в покой (состояние компонента — выбранная вкладка, строка — сохраняется).

## 11. Как придумать фишку
### Вопросы (по порядку)
1. Что на этой странице есть **только здесь**? (оборудование, жест, схема, документ: ринг, мешок, рабица, маховик, пульт, лампа, табло, ковёр, знак движения.)
2. Какое **одно** место страницы читатель понимает хуже всего? (разница направлений, ход занятия, выбор зала, строка таблицы.)
3. Можно ли показать это **движением предмета** по действию читателя, не меняя текста?
4. Что увидит человек **без мыши** (телефон, планшет), **без JS**, **с reduce**? Если ничего не потеряет — хорошо.
5. Не обещает ли движение результат, срок, цену, бесплатность?
6. Сколько стоит: новые узлы в разметке (байты), свой JS (строки), риски для движка, высота телефона.

### Таблица штурма (в промте v1, §2)
6–10 идей, по каждой: идея · польза · риски · решение (берём / нет и почему). Обязательно своя предметная идея + серийные лёгкие (F10, F22, F23, F29). Отказы записываются — они не предлагаются снова без новых данных (`03_RULES_FACTS.md` §6).

### Критерии «берём»
- польза формулируется одной фразой про читателя;
- работает по действию или одним показом, конечна;
- без JS / reduce / forced / печать — статично и полно;
- не вставляет узлы, не трогает узлы движка;
- не удлиняет телефон;
- проверяется числами (координаты, время, `getAnimations()`=0).

### Типовые отказы (уже отклонялись)
| Идея | Почему нет |
|---|---|
| Фон, который движется сам / бесконечное вращение | нет действия читателя, отвлекает, «круг не вращается бесконечно» |
| Счётчик цен (`count`) | цены не крутим (стандарт 11) |
| Второй мотив на странице (маховик-фон рядом со схемой) | один мотив на страницу |
| Заливка контурного слова в финале | решение П12 |
| Наклон/«3D» карточек ради эффекта | декор, не предмет |
| Шкала цены с разной шириной карточек | честного масштаба нет на всех ширинах |
| Движение, которое заходит «дальше нарисованного» | читается как обещание результата |
| Касание строк таблицы как кнопок | строки не кнопки — нужна настоящая кнопка или автопоказ |
| Связывать блоки скриптом напрямую | блоки автономны; только атрибуты (`data-cue`) или события |

## 12. Доступность и режимы — чек-лист
- Фокус: `#id.ag-scope :is(a,button,summary,input):focus-visible{outline:3px solid <акцент или тушь>;outline-offset:3px}`; у жёлтой кнопки цвет обводки — текст; панели вкладок — свой фокус 3 px.
- Цели нажатия ≥ 44×44; текстовая ссылка — `padding:10px 0`.
- Клавиатура: вкладки — стрелки по кругу, Home/End, `tabindex="0"` только у выбранной вкладки и только у видимой панели; выбор одного из нескольких — кнопки `aria-pressed` в `role="group"`, одна нажата всегда; независимые отметки (чек-лист «в сумке») — отдельные `button[aria-pressed]` без группы.
- F23 (нажатие) — у всех кнопок с видимой областью: пилюли, вкладки, переключатели, «−/+»; у текстовых ссылок — нет.
- Декор — `aria-hidden="true" focusable="false"`; свои узлы фишки — внутри такого SVG, без `role`, `tabindex`, `aria-live`.
- Текст, видимый только глазу (подписи «за занятие»), — `aria-hidden`; смысловой, но скрытый — `.ag-vh` («— выгоднее всего»).
- `prefers-reduced-motion`: переходы `.01ms`, своё движение не запускается и останавливается на лету, состояние сохраняется.
- `forced-colors`: фоны (`background`) пропадают — смысловые формы (узел, полоса, отметка) делай рамкой (`border`) или SVG-штрихом; подложки и зерно скрыты; выбранное — `border:3px solid Highlight`; штрихи — `CanvasText`, активное — `Highlight`.
- Печать: всё раскрыто (ответы FAQ, все панели, все строки), декор и переключатели скрыты, `stroke-dasharray:none`, узлы движка видимы (правило печати из §7).
- Без JS: вкладки и переключатели скрыты (`hidden` в разметке, JS снимает), панели столбцом, «Раскрыть все» скрыта, всё видно.
- Контраст ≥ 4,5:1; axe-core (WCAG 2.2 AA) — 0 нарушений на 1440, 1024, 390, 390 reduce, 320, без JS и в раскрытых состояниях.

## 14. Кадры, аналитика, особенности Tilda
**Кадры.** Только кадры владельца по URL `static.tildacdn…`; подпись и alt — по тому, что видно (ты кадр не видишь — попроси пользователя прислать снимок или опиши как «не сверено» и подпиши только адресом). Первый экран: `width`, `height`, `fetchpriority="high"`, без `loading`, без появления. Остальные — `loading="lazy" decoding="async"`. Нет кадра — слот на `<figure>`: `data-ag-slot="<ID>-<имя>" data-ag-ratio="4:5" data-ag-brief="что снять"` + монограмма или тон, без пунктира. Без стоков и сгенерированных людей/залов; дети — только с разрешения родителей.

**Аналитика.** На ссылках и кнопках: `data-ag-track="<цель>" data-ag-params='{"from":"<место>",…}'` (JSON в одинарных кавычках). Цели — из существующих (`request_start`, `phone_click`, `club_select`, `direction_select`, `nav_click`, `page_jump`, `faq_open`, `route_click` …), новые имена не заводить; в параметрах — только `from`, `club`, `direction`, `to`, `page`, `tab`, `target`; никаких личных данных.

**Запись и параметры.** Главная кнопка — `/request?…` (так во всех блоках; состояние формы заявки — вопрос владельца I001, не решай его в блоке), вторая — телефон `tel:+79171075179`. На странице клуба — `/request?club=<клуб>`, на странице направления — `/request?direction=<адрес страницы направления>&club=<клуб>`. Значения: клуб `boxing` (Галактионовская, 81, `/boxing`), `mma` (Чкалова, 72, `/mma`), `gym` (Ново-Садовая, 106Б, `/gym`), `nofitness` (Молодогвардейская, 56, `/nofitness`), `all`; направление — адрес страницы (`boxing-samara`, `muay-thai-samara`, `kickboxing-samara`, `mma-samara`, `grappling-samara`, `functional-training`, `cycle-samara`, `stretching-samara`). `from` в `data-ag-params` — `<страница>_<роль>` (`dir08_hero`, `dir08_faq`) или `hero` / `cta` / `faq`.

**Tilda.** Блок — запись T123 «HTML-код», отступы 0/0; один блок — одна запись. Стили Tilda агрессивны: сброс внутри блока типовыми селекторами `#id p` (1,0,1), а ссылки, кнопки и фокус — с `.ag-scope` (`#id.ag-scope a`), иначе `#allrecords a` перебивает. Корень `overflow-x:clip` (не `hidden` — ломает `sticky`). `scroll-margin-top:96px` под шапку. Title/Description/OG — в настройках страницы, не в блоке. Публикация, индексация, 301, удаление записей — только по прямому поручению.

| Плохо | Надо |

| Анимация бесконечно / по таймеру без действия | по действию или один показ |
| Отчёт «всё проверено» без стенда | группы и `not_tested` с причиной |

### Длинный код в ChatGPT (блок 25–50 КБ ≈ 8–15 тыс. токенов)
1. **Есть Python / файлы** — собери файл и дай ссылку на скачивание (лучший путь). Движок вставляй чтением `ENGINE_TEMPLATE.html`, не набором.
2. **Есть Canvas** — блок целиком в Canvas, один блок — один документ.
3. **Только чат** — частями по фиксированным разрезам: (1) шапка → `</section>`; (2) `<style>`…`</style>`; (3) свой `<script>`; (4) движок — **не перепечатывать**: строка-метка `<!-- ВСТАВИТЬ ДВИЖОК ИЗ ENGINE_TEMPLATE.html -->` и `</div>`. 4. Не сокращай: никаких «…», «стили как раньше», «остальное без изменений».

## 20. Разбор от идеи до кода: «Три темпа на знаке» (DIR08-02, `/stretching-samara`)
Полный код — `ETALON_DIR08-02_v1.1.0_tempo.html`; механика и выдержки — `APOLLO_FEATURE_CARDS.md` §15.1.

**1. Вход.** Блок «Растяжка, мобилити или восстановление» — бумага, три колонки с одинаковыми строками (F08 уже сделан в v1.0.0: subgrid, подсветка строки мышью, переключатель строк < 1024). В шапке колонок — знаки 72×48: луч от точки с дугой (растяжка), круг со стрелками (подвижность суставов), волна с точкой (восстановление).
**2. Где непонятно читателю.** Строка «Как работают»: «Удержание положения, счёт ведёт тренер» / «Повторы без удержания, по кругу и обратно» / «Темп ниже обычного». Это разница **темпа** — её проще увидеть, чем прочесть.
**3. Идея.** Строка «Как работают» → три знака одновременно играют свой темп один раз (~3 с): луч поднимается от базовой линии до нарисованного угла, держит под счёт трёх точек и опускается; точка обходит круг туда и обратно дважды; точка медленно проходит волну.
**4. Ревью поймало.** «Луч глубже» пересекал засечку и читался как обещание прогресса → луч поднимается **до** нарисованного угла (26,57°), не дальше. Нужна готовность прорисовки (иначе показ поверх рисующихся линий). Автопоказ не привязан к строке → на время показа атрибут `data-cue="2"` подсвечивает строку (ПК) или кнопку «Как работают» (< 1024). Переход мыши по строке через колонки перезапускал → снятие подсветки с задержкой 220 мс, пуск только при переходе «не 2 → 2».
**5. Разметка — заранее, без `data-ag-anim`**, последними в каждом знаке:
```html
              <g class="ag-zc__tp" data-ag-tempo="hold">
                <path class="ag-zc__tray" d="M14 38L60 15"/>
                <circle class="ag-zc__tc" cx="22" cy="44" r="2.6"/>
                <circle class="ag-zc__tc" cx="30" cy="44" r="2.6"/>
                <circle class="ag-zc__tc" cx="38" cy="44" r="2.6"/>
              </g>
```
**6. CSS покоя** — узлы скрыты, знак как в v1.0.0; поворот луча вокруг (14,38):
```css
  #ag-dir08-02 .ag-zc__tp{opacity:0;pointer-events:none;}
  #ag-dir08-02 .ag-zc__sign .ag-zc__tray{stroke:var(--ochre);stroke-width:3.2;transform-box:view-box;transform-origin:14px 38px;transform:rotate(26.57deg);}
  #ag-dir08-02 .ag-zc__trot{transform-box:view-box;transform-origin:36px 24px;}
  #ag-dir08-02 .ag-zc__tglide{transform-box:view-box;transform-origin:0 0;transform:translate(6px,30px);}
```
**7. JS** — WAAPI, окно 3000 мс, все три знака стартуют и заканчивают вместе; луч `rotate(26.57deg) → 0` за 20 % окна, держит до 70 %, возврат к 90 %; точки счёта загораются в 600 / 1100 / 1600 мс; круг — `rotate 0 → 360 → 0 → 360 → 0` четвертями окна; волна — 29 точек `getPointAtLength` (только чтение пути) с плавностью в выборке. Пуски: автопоказ один раз (три знака ≥ 60 % и 400 мс, прорисовка закончена, нет чужого `data-cue`), мышь ≥ 1024 — переход подсветки на строку 2 (через `MutationObserver` атрибутов), < 1024 — выбор «Как работают» (повторное нажатие — заново, уход — покой). Reduce — не играет и останавливает на лету; смена медиазапросов и скрытая вкладка — `cancel()`.
**8. Проверки (30 сценариев):** автопоказ на 1440/1024/768/390/320 после прорисовки, один раз, покой через 3 с, вставок узлов 0; наведение до прорисовки — нет; строка через три колонки — один пуск; 11 быстрых наведений — 1 пуск и покой; reduce посреди показа; ресайз 1440→900; сенсорный 1280 — только автопоказ; переключатель с клавиатуры; forced; печать; снимок покоя = v1.0.0 (разница пикселей 0); 02 и подсказка 03 идут по очереди.
**9. Поправки после проверок (§9 промта):** подсказка 03 и автопоказ 02 помещались в один экран → `data-cue`; точки счёта на телефоне мелкие → радиус 2,2 → 2,6.
