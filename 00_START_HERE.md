# Пак передачи · сайт Apollo Gym (Самара) · 02.10.2026

## Как запустить
### Claude — проект (лучше всего)
1. Новый проект, например «Сайт Аполло · дизайн и движение».
2. **Инструкции проекта** — весь текст `01_SYSTEM_PROMPT.md` (если в проекте уже стоит инструкция v10 — заменить ею).
3. **Знания проекта** — `02`…`08` и файлы `knowledge/` (12 файлов). Больше ничего.
4. Новый диалог: первое сообщение ниже + файлы `kits/stretching-samara/` (по одному, до 20 за раз).
5. Если в проекте включено выполнение кода — можно приложить весь zip пака: ассистент распакует и будет работать в профиле Б.

### Claude — обычный чат
Приложить `HANDOFF_ALL_IN_ONE.md`, `knowledge/FACTS_v10.md` + файлы комплекта страницы из `kits/…` (порядок важности — в его README) и отправить первое сообщение.

### Claude Code / агент с терминалом (профиль А)
Распаковать пак в рабочую папку, сказать: «Прочитай 00_START_HERE.md и 01_SYSTEM_PROMPT.md, профиль А». Для `/trainers`, `/tournaments` и страниц тренеров дополнительно приложить рабочий архив `apollo_work_*.zip`.

### ChatGPT — проект или свой GPT
1. **Instructions** — весь текст `01_SYSTEM_PROMPT.md`.
2. **Files** — `HANDOFF_ALL_IN_ONE.md`, `knowledge/FACTS_v10.md`, `knowledge/DECISIONS_v11.md`, `knowledge/FALLBACKS.md`, `knowledge/CODE_RULES_v10.md`, `knowledge/COPY_STANDARD.md` (лимит файлов у проектов невелик — ядро важнее).
3. В чат — первое сообщение + файлы `kits/<страница>/`. С включённым анализом данных (Python) можно приложить весь zip — профиль Б.

### ChatGPT — обычный чат
Приложить `HANDOFF_ALL_IN_ONE.md`, `knowledge/FACTS_v10.md`, `knowledge/FALLBACKS.md` + файлы комплекта страницы (`kits/<страница>/`, порядок важности — в его README), первое сообщение.

## Первое сообщение (скопировать)
```
Продолжаем сайт Apollo Gym. Прочитай пак передачи (01–08 или HANDOFF_ALL_IN_ONE) и скажи:
1) свой профиль среды (А/Б/В) и что тебе от меня нужно для сверки теста;
2) что срочно по 02_PROJECT_STATE;
3) план прохода для следующей страницы.
Затем работаем со страницей https://apolloboxing.tilda.ws/stretching-samara — все блоки, как в прошлых проходах: промт → ревью → v2 → сборка → проверки → выдача в удобном для копирования виде. Не забывай мобильную версию и проверять себя.
```
Дальше можно писать как раньше: ссылка на страницу + «теперь работаем с этой страницей…».

## Чего в паке нет и почему
- **Имена из записей справочника тренеров «не публикуются»** и все файлы, где они встречаются (часть данных и текстов пака v8, снимки старых страниц, стенд-тесты фазы 1). Вместо них — список разрешённых имён и проверка по хешам. Для `/trainers`, `/tournaments`, страниц тренеров нужен рабочий архив (профиль А).
- **Рабочий архив целиком** (все версии всех блоков, сборщики фазы 1) — внутренний; в паке только последние версии и инструменты прохода.
- **Блоки `/request` v3.1.0 / v1.3.0 / REQUEST-03** из диалога 30.09 — их файлов здесь не было; код — из Tilda.
- **Фото** — только заглушки для стенда; настоящие кадры — по URL tildacdn в блоках.
